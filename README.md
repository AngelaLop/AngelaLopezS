# Angela Lopez - Portfolio Website

A clean, simple portfolio website built with HTML, CSS, and JavaScript.

## 🚀 Features

- ✅ **Dark Mode** - Toggle between light and dark themes
- ✅ **Image Zoom** - Click images to zoom (Medium-style)
- ✅ **Progress Bar** - Shows reading progress at top
- ✅ **Masonry Layout** - Responsive project grid
- ✅ **Smooth Scrolling** - Smooth navigation
- ✅ **Responsive Design** - Works on all devices
- ✅ **No Build Process** - Just edit and refresh!

## 📁 Structure

```
├── index.html          # Main page
├── styles.css          # All styles
├── script.js           # JavaScript features
├── assets/             # Images and videos
│   ├── img/
│   └── video/
└── README.md           # This file
```

## 🎨 Customize

### Update Content
- Edit `index.html` - Change text, add projects, update links

### Update Styles
- Edit `styles.css` - Change colors, fonts, spacing
- CSS variables at top for easy color changes

### Update Social Links
- Edit the contact section in `index.html`
- Update email, LinkedIn, GitHub links

## 🌐 Deploy to GitHub Pages

1. Push to GitHub
2. Go to Settings > Pages
3. Select `main` branch
4. Done! Your site is live at `https://AngelaLop.github.io/AngelaLopezS/`

## 💻 Local Development

Just open `index.html` in your browser! No server needed.

Or use Python:
```bash
python -m http.server 8000
```

Then visit: `http://localhost:8000`

## 📝 Adding Projects

Copy a project card in `index.html` and update:
- Image/video source
- Title
- Description
- Tags

## 🎯 Features Explained

- **Dark Mode**: Click the 🌓 button in navigation
- **Image Zoom**: Click any image with `zoom-image` class
- **Progress Bar**: Automatically shows at top when scrolling
- **Masonry**: Projects automatically arrange in grid

That's it! Simple and effective.
